# ShelfOS Brand Policy — Draft

ShelfOS source code is open source.

The ShelfOS name, logo, wordmark, and official release identity should still distinguish official builds from forks.

## Community use

Welcome:

- referring to ShelfOS by name
- linking to the project
- screenshots/reviews/tutorials
- identifying a fork as "based on ShelfOS"
- contributing themes/features upstream

## Public redistribution of forks

Recommended:

- use a distinct app/package identifier
- clearly state that the build is unofficial
- avoid implying maintainer endorsement
- use distinguishable naming/iconography when distributing publicly

## Official branding

Official ShelfOS store listings, signing identities, and release channels are controlled by project maintainers.

Open-source licensing of the code does not grant access to official release credentials.

This policy should be formalized before major third-party redistribution or commercial adoption.
