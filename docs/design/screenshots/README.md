# Phase 0 application screenshots

These captures are local validation artifacts, excluded from Git. Public README
screenshots are deferred until the first fully working version is ready.

Captured from the actual ShelfOS debug application on an AOSP API 35 emulator.
These are implementation evidence, separate from the approved concept reference.
All publication covers are original geometric illustrations generated in Compose.

- `classic-phone.png`: compact window, three-column grid and bottom navigation.
- `classic-expanded.png`: expanded window, compact rail and selected-item details.
- `dark-expanded.png`: the same information architecture in Dark, after force-stop
  and cold relaunch with the selected theme persisted in Room.

Expanded captures use a 1600×1000, mdpi emulated window. The phone capture uses
1080×1920 at 420dpi. Android system bars/taskbar belong to the emulator, not ShelfOS.
